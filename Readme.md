NEXUS – Stock Trading Platform

CodeAlpha Java Internship Project

Project Overview

NEXUS is a Java-based Stock Trading Platform developed using Java Swing. It provides an interactive dashboard where users can view stock market data, buy and sell stocks, manage their portfolio, and track their trading performance.

Features

- Market Data Display: Displays stock symbols and simulated stock prices.
- Buy and Sell Operations: Allows users to buy and sell stocks.
- Portfolio Management: Tracks owned stocks and available cash.
- Performance Tracking: Displays portfolio value and profit/loss.
- Transaction History: Records buy and sell transactions.
- Data Persistence: Saves portfolio and transaction data using file handling.
- Interactive Dashboard: Dark-themed graphical user interface.

Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- File Handling
- VS Code

OOP Concepts Implemented

- Classes and Objects
- Encapsulation
- Constructors
- Methods
- Object interaction

How to Run the Project

1. Install Java JDK on your computer.

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Open the Java source file.

5. Compile the program:
   
   javac Main.java

6. Run the application:
   
   java Main

Important Note

This project uses simulated stock market prices for demonstration and educational purposes. It does not connect to a live stock exchange.
